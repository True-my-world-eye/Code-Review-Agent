## 3. 环境与运行

- Python 3.12.7，虚拟环境 `.venv/`（`uv` 创建）
- 安装依赖：`uv pip install -r requirements.txt`
- 运行测试：`.venv\Scripts\python.exe -m pytest tests/ -v`
- 运行程序：`.venv\Scripts\python.exe main.py --help`
