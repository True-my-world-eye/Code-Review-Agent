## 2. 打包步骤（提交前执行）

```powershell
# 1) 确认在 main 且干净
git status                      # 应无未提交改动
git log --oneline -10           # 确认 docs/m7、docs/m8 已合并

# 2) 用仓库根目录打包（不含 .venv 与会话数据，.gitignore 已排除密钥）
#    用你自己的「学号姓名」替换下面示例
Compress-Archive -Path ".\*" -DestinationPath "10086张三.zip"
# 有 WinRAR/RAR 格式要求时：
#   用 WinRAR 右键 → 添加到 "10086张三.rar"，确保 < 200M
```

**打包前必查**：
- [ ] `config.yaml` 不在压缩包内（含真实 Key，已被 gitignore，确认 zip 里没有）
- [ ] `Homework 1.pptx` 可不打包（课程原件）
- [ ] 压缩包体积 < 200M（排除 `.venv/`：如被打进去，先删除或用选择性打包）

```powershell
pip install -r requirements.txt

python main.py review <你的代码路径>    # 或 python main.py web
```
