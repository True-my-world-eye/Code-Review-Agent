# 演示视频脚本（≤ 1 分钟 · 可选提交物）

> 用途：作业提交的演示视频（可选，1 分钟以内）。按镜头顺序录制即可，
> 每个镜头标注了预计时长与画面要点，总时长控制在 55 秒左右留缓冲。

## 录制准备

- 终端：Windows Terminal，字号调至 16pt+，主题浅色或深色高对比
- 浏览器：Chrome/Edge，先打开 http://127.0.0.1:8000 并配好 Key
- 演示素材：`examples/app_demo.py`（已埋 6 类典型缺陷）
- 录屏工具：Win+G（Xbox Game Bar）或 OBS，只录窗口不录桌面

## 分镜脚本

| # | 时长 | 画面 | 配音/字幕要点 |
|---|------|------|----------------|
| 1 | 0–5s | 打开 README，扫一眼项目标题与四大特性 | "代码审查 Agent：输入代码，自动审查并给出分级修复建议" |
| 2 | 5–15s | `python main.py review examples/app_demo.py`，时间线滚动（read_file / run_lint 实时可见） | "Agent 自主读取文件、调用 ruff 真实检查——每一步都可见" |
| 3 | 15–30s | 报告表格出现：4 严重 / 3 警告 / 1 建议，逐行展示 SQL 注入、eval 等命中项 | "预埋缺陷全部命中：注入、硬编码密钥、异常吞噬……行号精确" |
| 4 | 30–45s | 切到浏览器 Web 界面：设置面板展示服务商下拉 / 测试连接（绿色 ✓）→ 粘贴代码 → 开始审查 → 时间线 + 报告卡片 | "Web 端可视化配置 DeepSeek/MiMo 等服务商，同一 Agent 内核" |
| 5 | 45–52s | Web 报告卡片点「应用修复」→ 确认弹窗 → 变绿"已应用修复（含备份）" | "一键修复：确认后执行并自动备份" |
| 6 | 52–57s | 终端跑 `python -m pytest tests/ -q` → `120 passed` | "120 个自动化测试全部通过" |

## 后期提示

- 全程不出现完整 API Key（设置面板中 Key 本就脱敏，放心录）
- 导出分辨率 1080p，总时长 ≤ 60s，命名 `演示视频.mp4`
